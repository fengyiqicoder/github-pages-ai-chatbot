tidydate Install Usage Tokens FAQ

Format dates in one call.

tidydate is a 1 kB date formatter for JavaScript. No dependencies, no configuration, and it works in Node and in the browser.

v2.3.01 kB gzippedMIT license

Install

npm install tidydate

Or load it from a CDN with a script tag: https://cdn.example.com/tidydate@2/tidydate.min.js. Node 18 or newer is required.

Usage

import { format, fromNow } from "tidydate";

format(new Date(), "YYYY-MM-DD");        // "2026-11-12"
format(new Date(), "D MMM YYYY, HH:mm"); // "12 Nov 2026, 09:30"
fromNow("2026-11-10");                   // "2 days ago"

format(date, pattern, locale) takes a Date, a timestamp or an ISO string. The third argument is an optional locale such as "fr" or "ja"; month and weekday names come from the built-in Intl API, so every locale your runtime knows is supported.

FAQ

Does it handle time zones?

Yes. Pass { timeZone: "Asia/Tokyo" } as the last argument and the date is formatted in that zone. Without it, the local time zone is used.

Can it parse dates?

No. tidydate only formats. To parse, use new Date() with an ISO string, or the Temporal API.

Does it work with TypeScript?

Yes. Type definitions ship with the package, so there is nothing extra to install.

How do I report a bug?

Open an issue on GitHub with the input, the pattern and the output you expected. Fixes for confirmed bugs usually ship within a week.
